# Secure Code Assessment

## Description

This project was developed as part of the CODSOFT Cyber Security Internship.

The project demonstrates how to identify common security vulnerabilities in a Python application and provides recommendations to improve security.

## Files

- `vulnerable_app.py` – Sample Python application with intentional security flaws.
- `security_report.md` – Analysis of vulnerabilities and recommended fixes.
