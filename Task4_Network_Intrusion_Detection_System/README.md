# Network Intrusion Detection System

## Description

This project is a basic Network Intrusion Detection System (NIDS) developed for the CODSOFT Cyber Security Internship.

It monitors live network traffic using Scapy and detects suspicious activity based on the number of packets received from a single IP address.

## Features

- Live packet monitoring
- Displays source IP addresses
- Counts packets from each source
- Generates alerts for suspicious traffic

## Technologies Used

- Python
- Scapy
